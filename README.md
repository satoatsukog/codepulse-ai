# CodePulse AI

> Advanced client-side code audit, security vulnerability scanner, and refactoring suite built with Next.js and Tailwind CSS.

## Features

- **Multi-language Support:** Instant review workflows for TypeScript/JavaScript, Python, C#, and Go.
- **Security Risk Assessment:** Automated risk level detection (`LOW`, `MEDIUM`, `HIGH`) and vulnerability highlights.
- **Real-time Code Metrics:** Live calculation of SLOC (Source Lines of Code), Cyclomatic Complexity, and Technical Debt.
- **Side-by-Side Diff View:** Visual comparison of code before and after AI refactoring.
- **Customizable UI Themes:** Switch between *Dracula*, *GitHub Dark*, and *Monokai* color schemes.
- **Report Exporting:** Download comprehensive audit findings as `.md` markdown reports.
- **Audit History:** Local session tracking to quickly jump back to past reviews.

## Tech Stack

- **Framework:** Next.js (React / App Router)
- **Styling:** Tailwind CSS
- **Language:** TypeScript

## Architecture & Tech Stack

This project is built as a **high-performance, client-side interactive demonstration** designed for instant response without server latency or external API token requirements.

* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
* **Icons:** Lucide React
* **Engine:** Client-side Code Metrics Parser & Interactive Mock Audit System

> **Note:** The audit system currently uses an internal client-side simulation engine to demonstrate instant UI/UX capabilities, vulnerability reporting, code metrics calculation, and diff comparisons without requiring external LLM API keys.
